All three functions live on `Handler` in `src/Presentation/LambdaFunction/LambdaFunction.cs`, each marked `[LambdaFunction]`. Requests are read case-insensitively. Responses use the camelCase property names shown here, and properties with no value are left out.

The image runs `GetMovies` unless you pass a different handler name. [Lambda Annotations](https://github.com/aws/aws-lambda-dotnet/tree/master/Libraries/src/Amazon.Lambda.Annotations) generates the class each one names, and `src/Presentation/serverless.template` lists them all:

```text
Presentation::CleanLambdaFunction.Presentation.LambdaFunction.Handler_GetMovies_Generated::GetMovies
Presentation::CleanLambdaFunction.Presentation.LambdaFunction.Handler_GetAuthors_Generated::GetAuthors
Presentation::CleanLambdaFunction.Presentation.LambdaFunction.Handler_GetReviews_Generated::GetReviews
```

In your own solution, `CleanLambdaFunction` is replaced by the name you chose.

## GetMovies

Lists movies ordered by title, one page at a time, optionally only those whose title contains a search term.

### Request

| Property | Type | Default | Rules |
| --- | --- | --- | --- |
| `query` | string | none | Up to 100 characters. Matches the title, ignoring case |
| `offset` | integer | `0` | 0 or more |
| `limit` | integer | `10` | 1 to 50 |

```json
{ "query": "global", "offset": 0, "limit": 2 }
```

### Response

A [page](#pages) of movies.

| Property | Type | Description |
| --- | --- | --- |
| `id` | guid | The movie's id |
| `title` | string | The movie's title |
| `reviewCount` | integer | How many reviews the movie has |
| `averageStars` | number | The average rating to one decimal place. Left out when there are no reviews |

```json
{
  "items": [
    { "id": "30fca414-247a-779e-105a-d81aa2506f58", "title": "Assimilated global infrastructure", "reviewCount": 1, "averageStars": 1 },
    { "id": "c27d6600-79a6-9346-2595-a52b7f07dc3e", "title": "Automated global alliance", "reviewCount": 3, "averageStars": 3.3 }
  ],
  "totalCount": 2
}
```

## GetAuthors

Lists authors ordered by last name then first name, one page at a time, optionally only those whose name contains a search term.

### Request

The same as [GetMovies](#request). `query` matches anywhere in the full name, written first name then last name.

### Response

A [page](#pages) of authors.

| Property | Type | Description |
| --- | --- | --- |
| `id` | guid | The author's id |
| `firstName` | string | The author's first name |
| `lastName` | string | The author's last name |
| `reviewCount` | integer | How many reviews the author has written |
| `averageStars` | number | The average rating they give. Left out when there are no reviews |

```json
{
  "items": [
    { "id": "01fa8b58-05d2-abd4-e55c-2633222dd0a5", "firstName": "Jana", "lastName": "Auer", "reviewCount": 10, "averageStars": 2.6 },
    { "id": "1cc2ad51-61c5-63ee-dd6e-15308cfe6e51", "firstName": "Caroline", "lastName": "Bins", "reviewCount": 12, "averageStars": 2.7 }
  ],
  "totalCount": 15,
  "nextOffset": 2
}
```

## GetReviews

Lists reviews ordered by movie then author, one page at a time, optionally only those of one movie, by one author, or both.

### Request

| Property | Type | Default | Rules |
| --- | --- | --- | --- |
| `movieId` | guid | none | Only reviews of this movie |
| `authorId` | guid | none | Only reviews by this author |
| `offset` | integer | `0` | 0 or more |
| `limit` | integer | `10` | 1 to 50 |

```json
{ "movieId": "e159975e-4e6a-1ffd-713e-1eb9d8d4a593", "limit": 2 }
```

### Response

A [page](#pages) of reviews.

| Property | Type | Description |
| --- | --- | --- |
| `id` | guid | The review's id |
| `stars` | integer | The rating, from 1 to 5 |
| `reviewedMovie` | object | The reviewed movie's `id` and `title`. Its `reviewCount` is always 0 here, so use GetMovies for the real numbers |
| `reviewAuthor` | object | The author's `id`, `firstName` and `lastName`. Its `reviewCount` is always 0 here, so use GetAuthors for the real numbers |

```json
{
  "items": [
    {
      "id": "969cb90c-95ae-9189-1e52-0b38d34a911b",
      "stars": 4,
      "reviewedMovie": { "id": "e159975e-4e6a-1ffd-713e-1eb9d8d4a593", "title": "Assimilated disintermediate adapter", "reviewCount": 0 },
      "reviewAuthor": { "id": "1cc2ad51-61c5-63ee-dd6e-15308cfe6e51", "firstName": "Caroline", "lastName": "Bins", "reviewCount": 0 }
    },
    {
      "id": "a5ebd747-0408-0a96-1af1-eb5cb93bc814",
      "stars": 1,
      "reviewedMovie": { "id": "e159975e-4e6a-1ffd-713e-1eb9d8d4a593", "title": "Assimilated disintermediate adapter", "reviewCount": 0 },
      "reviewAuthor": { "id": "1cc2ad51-61c5-63ee-dd6e-15308cfe6e51", "firstName": "Caroline", "lastName": "Bins", "reviewCount": 0 }
    }
  ],
  "totalCount": 6,
  "nextOffset": 2
}
```

## Pages

Every function returns one page of results.

| Property | Type | Description |
| --- | --- | --- |
| `items` | array | The results on this page |
| `totalCount` | integer | The number of results across every page |
| `nextOffset` | integer | The `offset` that fetches the next page. Left out on the last page |

To read everything, start at `offset` 0 and keep sending the `nextOffset` back until it's missing.

## Errors

Errors come back in Lambda's standard error format, with the exception type in `errorType`.

| `errorType` | When |
| --- | --- |
| `ValidationException` | A request breaks one of the rules above. `errorMessage` lists every rule it broke |
| `NotFoundException` | A function that gets one thing by id, like the one in [Add a function](../../guides/add-a-function/), can't find it |
| `TaskCanceledException` or `OperationCanceledException` | The invocation ran out of time and the handler stopped the work |

```text
Validation failed:
 -- Limit: A limit must be between 1 and 50. Severity: Error
```
