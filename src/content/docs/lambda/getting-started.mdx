By the end of this page you'll have your own solution, a container running it, and a function that answers back. It takes about five minutes, or ten if Docker decides to download the internet first.

## Before you start

You need the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) and [Docker](https://www.docker.com/products/docker-desktop). You don't need an AWS account yet. The container image ships with the Lambda runtime emulator, so your laptop can pretend to be AWS for a while.

## Make it yours

<Steps>

1. Install the template from NuGet.

   ```bash
   dotnet new install CleanLambdaFunction.Template
   ```

2. Create a solution. The name becomes your namespace, project names and folder, so pick something you're happy to see a lot of.

   ```bash
   dotnet new cleanlambdafunction --name WorksOnMyMachine.Reviews --authorName "Your Name"
   cd WorksOnMyMachine.Reviews
   ```

   Rather click? The template shows up in the new project dialog in Visual Studio and Rider with the same options. Fill them in properly. You never know who's reading and handing out .NET Rocks mugs... Hi Richard!

3. Have a look around. Everything you need is already here.

   <FileTree>
   - WorksOnMyMachine.Reviews.slnx
   - Dockerfile
   - docker-compose.yml
   - src/
     - Application/ the rules, queries and validation
     - Infrastructure/ the database and repositories
     - Presentation/ the Lambda handler
   - tests/
     - Application.Tests.Unit/
     - Infrastructure.Tests.Integration/
     - Presentation.Tests.Integration/
     - Presentation.Tests.Unit/
   </FileTree>

4. Build the image and start it with sample data. Docker Compose turns the sample data on for you.

   ```bash
   docker compose up -d --build
   ```

5. Invoke the function. The emulator listens on port 9000 and answers the same way Lambda does.

   ```bash
   curl -X POST "http://localhost:9000/2015-03-31/functions/function/invocations" \
     -d '{"query":"space","limit":2}'
   ```

   You get a page of movies back:

   ```json
   {
     "items": [
       { "id": "cb188ef6-14e7-f85f-2f78-924c2ab26b28", "title": "Deep Space Gardeners", "reviewCount": 5, "averageStars": 3.4 },
       { "id": "dfefa450-5454-6a4d-a4aa-95a9b047c17b", "title": "Postcards from Outer Space", "reviewCount": 1, "averageStars": 3 }
     ],
     "totalCount": 4,
     "nextOffset": 2
   }
   ```

   The sample movies are all made up. *Deep Space Gardeners* averages 3.4 stars from five reviews, which seems fair for a film about weeding in zero gravity.

6. Run the tests while you're here.

   ```bash
   dotnet test
   ```

7. Tidy up when you're done.

   ```bash
   docker compose down
   ```

</Steps>
