## Run it

The three commands above create a solution and start it in Docker Compose. Then ask it for a page of movies. The container runs the Lambda runtime emulator on port 7350, so it answers the same way Lambda does:

```bash
curl -X POST "http://localhost:7350/2015-03-31/functions/function/invocations" \
  -d '{"query":"space","limit":2}'
```

The logs, traces and metrics go to the [Aspire dashboard](https://learn.microsoft.com/dotnet/aspire/fundamentals/dashboard/standalone) at [http://localhost:7352](http://localhost:7352), because `Console.WriteLine` is not an observability strategy.

There's no auth flag on this one. Invoked directly, AWS IAM decides who can call the function, and its HTTP routes take an API Gateway authorizer. [Secure the function](/lambda/guides/secure-the-function/) covers both.

## One of five

Clean Lambda Function is one of five [Lean Mean Clean Apps](/) templates. They share the same Application and Infrastructure layers, the same tests and the same pipeline. Only Presentation changes. Like a family, really. Same genes, different haircuts.
