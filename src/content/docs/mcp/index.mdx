## Two commands and you're in business

```bash
dotnet new install CleanModelContextProtocol.Template
dotnet new cleanmodelcontextprotocol --name Acme.Movies --authorName "Your Name"
```

That's a solution with three layers, four test projects, a Dockerfile and a CI pipeline. Now go and tell your team you've been working on it all week.

## What's in the box

## Run it

```bash
cd Acme.Movies
docker compose up -d
```

Then open the MCP Inspector at [http://localhost:6274](http://localhost:6274). It's already pointed at the server on [http://localhost:8080/mcp](http://localhost:8080/mcp), so connect, open **Tools** and start clicking. The logs go to Seq at [http://localhost:5341](http://localhost:5341).

Want it locked down? Pass `--authority` and `--audience` when you create the solution and `/mcp` needs a bearer token, with protected resource metadata so MCP clients can find your authorization server and sign in. Leave them off and it runs wide open, which is lovely on a laptop and less lovely in production.
