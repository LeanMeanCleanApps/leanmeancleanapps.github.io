Sooner or later you'll want to evict *Deep Space Gardeners* and move your own domain in. The tempting move is to delete `Movies`, `Authors` and `Reviews` first. Don't. Half the tests stop compiling, and the shared plumbing (paging, validation, logging, OpenAPI and telemetry) suddenly has nothing to exercise it, so coverage falls through the floor.

Go the other way round. Build your first slice beside the sample domain, prove it works end to end, then take the movies out. This guide adds cinemas, with `GET /api/cinemas` to list and search them and `POST /api/cinemas` to create one, and finishes with a solution that has no movies left in it. We ran every step on a fresh solution: it ends with 79 passing tests and 99.7% line coverage, and we ran it a second time from the page alone to be sure.

<Aside type="tip" title="Let Jacques do the typing">
  Each step names the skill in `.agents/skills/` that covers it. Point your coding agent at this page and your own domain, and it follows the same recipe.
</Aside>

The code below assumes you named the solution `WorksOnMyMachine.Movies`. Swap in your own name wherever you see it.

2. **Store and map it in `src/Infrastructure`** (`data-access-ef-core` and `mapping-with-mapperly`).

   Add the database model and its configuration beside the sample ones. Every model inherits `Entity`, which brings the id and the created and modified dates, and every configuration inherits `EntityConfiguration<T>`, which sets them up.

   ```csharp title="src/Infrastructure/Databases/MovieReviews/Models/Cinema.cs"
   namespace WorksOnMyMachine.Movies.Infrastructure.Databases.MovieReviews.Models;

   using System.Diagnostics.CodeAnalysis;

   [ExcludeFromCodeCoverage]
   internal record Cinema : Entity
   {
       public required string Name { get; init; }
   }
   ```

   ```csharp title="src/Infrastructure/Databases/MovieReviews/Configuration/CinemaConfiguration.cs"
   namespace WorksOnMyMachine.Movies.Infrastructure.Databases.MovieReviews.Configuration;

   using Microsoft.EntityFrameworkCore;
   using Microsoft.EntityFrameworkCore.Metadata.Builders;
   using Models;

   internal class CinemaConfiguration : EntityConfiguration<Cinema>
   {
       public override void Configure(EntityTypeBuilder<Cinema> builder)
       {
           base.Configure(builder);

           _ = builder.Property(c => c.Name).HasMaxLength(100).UseCollation(Collations.NoCase);
           _ = builder.HasIndex(c => c.Name);
       }
   }
   ```

   Then wire it in:

   - **`MovieReviewsDbContext.cs`:** add `public DbSet<Cinema> Cinemas => this.Set<Cinema>();` beside the other sets.
   - **`Mapping/MovieReviewsMapper.cs`:** add `using AppCinema = Application.Cinemas.Entities.Cinema;` and `using InfraCinema = Models.Cinema;` with the other aliases, and this method:

     ```csharp
     [MapperIgnoreSource(nameof(InfraCinema.DateCreated))]
     [MapperIgnoreSource(nameof(InfraCinema.DateModified))]
     public partial AppCinema ToDomain(InfraCinema cinema);
     ```

   - **`EntityFrameworkMovieReviewsRepository.cs`:** add `using Application.Cinemas;` and `using ApplicationCinema = Application.Cinemas.Entities.Cinema;`, add `ICinemasRepository` to the interfaces the class implements, and add a `Cinemas` region. The search reuses the repository's own `ContainsPattern` and `EscapeCharacter`, so a `%` or `_` in a search term matches itself, the same as for movies.

     ```csharp
     #region Cinemas

     public async Task<Page<ApplicationCinema>> GetCinemas(
         string? query,
         PageRequest page,
         CancellationToken cancellationToken)
     {
         var cinemas = this.context.Cinemas.AsQueryable();

         if (!string.IsNullOrWhiteSpace(query))
         {
             var pattern = ContainsPattern(query);

             cinemas = cinemas.Where(c => EF.Functions.Like(c.Name, pattern, EscapeCharacter));
         }

         var totalCount = await cinemas.CountAsync(cancellationToken);

         var result = await cinemas
             .OrderBy(c => c.Name)
             .ThenBy(c => c.Id)
             .Skip(page.Offset)
             .Take(page.Limit)
             .ToListAsync(cancellationToken);

         return new([.. result.Select(this.mapper.ToDomain)], page.Offset, page.Limit, totalCount);
     }

     public async Task<ApplicationCinema> CreateCinema(string name, CancellationToken cancellationToken)
     {
         var now = this.timeProvider.GetUtcNow().UtcDateTime;

         var cinema = new Cinema
         {
             Name = name,
             DateCreated = now,
             DateModified = now
         };

         _ = this.context.Add(cinema);

         _ = await this.context.SaveChangesAsync(cancellationToken);

         return this.mapper.ToDomain(cinema);
     }

     #endregion Cinemas
     ```

   - **`src/Infrastructure/DependencyInjection.cs`:** add `using Application.Cinemas;` and register the interface against the same repository, like the others:

     ```csharp
     _ = services.AddScoped<ICinemasRepository>(x =>
         x.GetRequiredService<EntityFrameworkMovieReviewsRepository>());
     ```

   - **`Extensions/MovieReviewsDbContextExtensions.cs`** (`sample-data`): give `local` and `docker` some cinemas to look at. Add this to `AddData` before `SaveChanges`:

     ```csharp
     var cinemas = new Faker<Cinema>()
         .UseSeed(Seed)
         .RuleFor(c => c.Id, f => f.Random.Guid())
         .RuleFor(c => c.Name, f => $"{f.Address.City()} Picture House")
         .RuleFor(c => c.DateCreated, f => f.Date.Past(refDate: ReferenceDate))
         .RuleFor(c => c.DateModified, f => f.Date.Past(refDate: ReferenceDate))
         .Generate(5);

     context.AddRange(cinemas);
     ```

   dotnet tool install --global dotnet-ef
   dotnet ef migrations add AddCinemas \
     --project ./src/Infrastructure \
     --output-dir Databases/MovieReviews/Migrations \

4. **Put it on endpoints in `src/Presentation`** (`expose-a-use-case` and `xml-docs-and-openapi`).

   The XML comments aren't decoration. They become the OpenAPI description, and a test fails if an operation or schema has none.

   ```csharp title="src/Presentation/Requests/CreateCinemaRequest.cs"
   namespace WorksOnMyMachine.Movies.Presentation.Requests;

   /// <summary>
   /// The details needed to create a cinema.
   /// </summary>
   public class CreateCinemaRequest
   {
       /// <summary>
       /// The name of the cinema, up to 100 characters.
       /// </summary>
       /// <example>The Astor</example>
       public string Name { get; init; } = string.Empty;
   }
   ```

   ```csharp title="src/Presentation/Endpoints/CinemaEndpoints.cs"
   namespace WorksOnMyMachine.Movies.Presentation.Endpoints;

   using Application.Common.Paging;
   using Mediator;
   using Microsoft.AspNetCore.Builder;
   using Microsoft.AspNetCore.Http;
   using Microsoft.AspNetCore.Http.HttpResults;
   using Microsoft.AspNetCore.Mvc;
   using Presentation.Requests;
   using Commands = Application.Cinemas.Commands;
   using Entities = Application.Cinemas.Entities;
   using Queries = Application.Cinemas.Queries;

   public static class CinemaEndpoints
   {
       public static WebApplication MapCinemaEndpoints(this WebApplication app)
       {
           var root = app.MapGroup("/api/cinemas")
               .WithTags("Cinemas");

           _ = root.MapGet("/", GetCinemas)
               .WithName(nameof(GetCinemas))
               .Produces<Page<Entities.Cinema>>()
               .ProducesValidationProblem()
               .ProducesProblem(StatusCodes.Status500InternalServerError);

           _ = root.MapPost("/", CreateCinema)
               .WithName(nameof(CreateCinema))
               .Produces<Entities.Cinema>(StatusCodes.Status201Created)
               .ProducesValidationProblem()
               .ProducesProblem(StatusCodes.Status500InternalServerError);

           return app;
       }

       /// <summary>
       /// List Cinemas
       /// </summary>
       /// <remarks>
       /// Returns one page of cinemas, ordered by name. Add a search term to return only the cinemas whose name
       /// contains it, ignoring case. To fetch the next page, add the limit to the offset.
       ///
       /// Sample request:
       ///
       ///     GET /api/cinemas?query=astor&amp;offset=0&amp;limit=10
       /// </remarks>
       /// <param name="query">The words to look for in the name, ignoring case. Leave it out to list every cinema.</param>
       /// <param name="offset">The number of cinemas to skip, 0 for the first page.</param>
       /// <param name="limit">The largest number of cinemas to return, from 1 to 50.</param>
       /// <response code="200">One page of Cinemas.</response>
       /// <response code="400">The search term, offset or limit is not valid.</response>
       /// <response code="500">An unexpected error occurred.</response>
       public static async Task<Ok<Page<Entities.Cinema>>> GetCinemas(
           [FromQuery] string? query,
           [FromServices] ISender sender,
           CancellationToken cancellationToken,
           [FromQuery] int offset = 0,
           [FromQuery] int limit = Paging.DefaultLimit)
       {
           return TypedResults.Ok(await sender.Send(new Queries.GetCinemas.GetCinemasQuery
           {
               Query = query,
               Offset = offset,
               Limit = limit
           }, cancellationToken));
       }

       /// <summary>
       /// Create a Cinema
       /// </summary>
       /// <remarks>
       /// Creates a cinema. The name can't be empty or longer than 100 characters.
       ///
       /// Sample request:
       ///
       ///     POST /api/cinemas
       ///     {
       ///         "name": "The Astor"
       ///     }
       /// </remarks>
       /// <param name="request">The cinema to create.</param>
       /// <response code="201">The Cinema that was created.</response>
       /// <response code="400">The request is not valid, for example the name is empty.</response>
       /// <response code="500">An unexpected error occurred.</response>
       public static async Task<Created<Entities.Cinema>> CreateCinema(
           [FromBody] CreateCinemaRequest request,
           [FromServices] ISender sender,
           CancellationToken cancellationToken)
       {
           var response = await sender.Send(new Commands.CreateCinema.CreateCinemaCommand
           {
               Name = request.Name
           }, cancellationToken);

           return TypedResults.Created((string?)null, response);
       }
   }
   ```

   There's no endpoint that gets one cinema by its id yet, so the 201 has no `Location` header. Add a `GetCinemaById` and switch to `TypedResults.CreatedAtRoute`, as `CreateReview` does, when you need one.

   Then register it:

   - **`Serialization/AppJsonSerializerContext.cs`** (`json-serialization`): add `using Application.Cinemas.Entities;`, then `[JsonSerializable(typeof(Cinema))]`, `[JsonSerializable(typeof(Page<Cinema>))]` and `[JsonSerializable(typeof(CreateCinemaRequest))]`.
   - **`OpenApi/DocumentInfoTransformer.cs`:** add `CreateTag("Cinemas", "Lookup all Cinemas, search them by name, or create new ones"),` to the tags.
   - **`Extensions/WebApplicationExtensions.cs`:** add `_ = app.MapCinemaEndpoints();` beside the other `Map*Endpoints()` calls.
   - **`--include-auth`:** if you created the solution with it, add `_ = root.RequireAuthorization();` after `WithTags`, as the other endpoint groups do.
   - **`Presentation.http`:** add a request for each endpoint, including one that fails validation.

## What's still called "movie reviews"

The database plumbing keeps its sample name: the `Databases/MovieReviews` folder, `MovieReviewsDbContext`, `EntityFrameworkMovieReviewsRepository`, the `MovieReviews` connection string and the `movie-reviews.db` file. They all work as they are. Everything in `src/Infrastructure` is `internal`, so renaming them later is a refactor that never reaches Application or Presentation. Do it when the name starts to bother you, and change the connection string in every `appsettings.*.json` and in `docker-compose.yml` at the same time.
