This page is about the template repository, not your solution. Your solution starts with a simpler pipeline, and [Set up CI](/minimalapi/guides/set-up-ci/) covers what it runs, along with every check the template runs on itself and what each one needs if you want to borrow it.

These are templates we build for fun, but the repository doesn't know that. Every pull request goes through the same checks, and some of them are allowed to say no.

## The rules on main

- Every change goes through a pull request, and every check must pass.
- Only the maintainer can merge. Pull requests from anyone are welcome, but the green button has one owner.
- Commits must be signed, and merges are squashed so the history stays readable.
- Release tags can't be moved or deleted once they exist, so a version always means the same code.
- Third-party GitHub Actions are pinned to a commit, not a tag, so nobody can swap them out from under us.

## Releases

New versions go to [NuGet](https://www.nuget.org/packages/CleanMinimalApi.Template) on the 1st of each month, but only when something outside the `.github` folder has changed. Publishing uses NuGet [trusted publishing](https://learn.microsoft.com/nuget/nuget-org/trusted-publishing), so there's no long-lived API key sitting in the repository waiting to leak. Each release gets a [GitHub release](https://github.com/LeanMeanCleanApps/CleanMinimalApi/releases) with generated notes and an SPDX bill of materials.

## The docs

These docs live on the [Lean Mean Clean Apps site](/), next to the other four templates, and they're built with [Starlight](https://starlight.astro.build) from the [site repository](https://github.com/LeanMeanCleanApps/leanmeancleanapps.github.io). Spotted a mistake? The **Edit page** link at the bottom of every page takes you straight to the file. The site also publishes an [`llms.txt`](/llms.txt), so your AI assistant can read the docs too. It still won't write the tests for you. Well, it might.
