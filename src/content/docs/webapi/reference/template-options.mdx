```bash
dotnet new cleanwebapi --name <NAME> [--authorName|-an <AUTHOR>] [--include-auth --authority|-iss <URL> [--audience|-aud <URL>]] [--output|-o <PATH>] [--no-restore]
```

| Option | Default | What it changes |
| --- | --- | --- |
| `--name`, `-n` | The current folder's name | Replaces `CleanWebApi` in every namespace, project, file and folder name, and names the output folder |
| `--authorName`, `-an` | `Stephen Walsh` | Sets the `Authors` and `Copyright` of the Presentation project, so the assembly credits you instead of us |
| `--include-auth` | off | Adds JWT bearer authentication. Off, the solution has no authentication code, settings or package at all |
| `--authority`, `-iss` | empty | Required with `--include-auth`. Sets `Authentication:Authority` in `appsettings.json`, the server that issues the tokens the API accepts |
| `--audience`, `-aud` | empty | Only used with `--include-auth`. Sets `Authentication:Audience` in `appsettings.json`, the audience those tokens must be issued for |
| `--output`, `-o` | A folder named after `--name` | Where the solution is created |
| `--no-restore` | off | Skips the package restore that otherwise runs as soon as the solution is created |

The usual `dotnet new` options such as `--dry-run` and `--force` work too. Run `dotnet new cleanwebapi --help` for the full list.

## In Visual Studio or Rider

Once the template is installed, it shows up in the new project dialog under its name, with the same options as labelled fields. Visual Studio restores the packages for you.

Both IDEs show **Authentication authority** and **Authentication audience (optional)** even when **Include authentication** is unticked, because they don't hide fields the way `dotnet new` does. They're only used when the box is ticked, and then the authority is required.

You'll need the .NET 10 SDK or later. Older SDKs get a polite note saying so instead of a half-made solution.

## Install, update and remove

| Task | Command |
| --- | --- |
| Install | `dotnet new install CleanWebApi.Template` |
| Check for updates | `dotnet new update --check-only` |
| Update | `dotnet new update` |
| Remove | `dotnet new uninstall CleanWebApi.Template` |

New versions are published on the 1st of each month when something has changed. See the [releases](https://github.com/LeanMeanCleanApps/CleanWebApi/releases) for what's new.
