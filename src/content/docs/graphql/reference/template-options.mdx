```bash
dotnet new cleangraphqlapi --name <NAME> [--authorName <AUTHOR>] [--authority <URL>] [--audience <URL>] [--output <PATH>]
```

| Option | Default | What it changes |
| --- | --- | --- |
| `--name`, `-n` | The current folder's name | Replaces `CleanGraphQLApi` in every namespace, project, file and folder name, and names the output folder |
| `--authorName` | `Stephen Walsh` | Sets the `Authors` and `Copyright` of the Presentation project, so the assembly credits you instead of us |
| `--authority` | empty | Sets `Authentication:Authority` in `appsettings.json`. When it's set, the API requires JWT bearer tokens issued by that server |
| `--audience` | empty | Sets `Authentication:Audience` in `appsettings.json`, the audience those tokens must be issued for |
| `--output`, `-o` | A folder named after `--name` | Where the solution is created |

The usual `dotnet new` options such as `--dry-run` and `--force` work too. Run `dotnet new cleangraphqlapi --help` for the full list.

## Install, update and remove

| Task | Command |
| --- | --- |
| Install | `dotnet new install CleanGraphQLApi.Template` |
| Check for updates | `dotnet new update --check-only` |
| Update | `dotnet new update` |
| Remove | `dotnet new uninstall CleanGraphQLApi.Template` |

New versions are published on the 1st of each month when something has changed. See the [releases](https://github.com/stphnwlsh/CleanGraphQLApi/releases) for what's new.
