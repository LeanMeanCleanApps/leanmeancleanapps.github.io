By the end of this page you'll have your own solution, a GraphQL API running on your machine, and a page of movies on your screen. It takes about five minutes, or ten if NuGet decides to download the internet first.

## Before you start

You need the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). [Docker](https://www.docker.com/products/docker-desktop) is optional, but it gets you the Aspire dashboard for the logs, traces and metrics, and a container you can ship, so it's worth having around.

## Make it yours

<Steps>

1. Install the template from NuGet.

   ```bash
   dotnet new install CleanGraphQLApi.Template
   ```

2. Create a solution. The name becomes your namespace, project names and folder, so pick something you're happy to see a lot of.

   ```bash
   dotnet new cleangraphqlapi --name WorksOnMyMachine.Movies --authorName "Your Name"
   cd WorksOnMyMachine.Movies
   ```

   Rather click? The template shows up in the new project dialog in Visual Studio and Rider with the same options. Fill them in properly. You never know who's reading and handing out .NET Rocks mugs... Hi Richard!

3. Have a look around. Everything you need is already here.

   <FileTree>
   - WorksOnMyMachine.Movies.slnx
   - Dockerfile
   - docker-compose.yml
   - src/
     - Application/ the rules, queries and validation
     - Infrastructure/ the database and repositories
     - Presentation/ the GraphQL schema
   - tests/
     - Application.Tests.Unit/
     - Infrastructure.Tests.Integration/
     - Presentation.Tests.Integration/
     - Presentation.Tests.Unit/
   </FileTree>

4. Run it. The `local` environment seeds sample data and logs to the console, so there's nothing to set up.

   ```bash
   dotnet run --project ./src/Presentation
   ```

5. Open Nitro, the GraphQL IDE, at [http://localhost:8080/graphql](http://localhost:8080/graphql). The schema is on the left, with every type and field described, and the editor autocompletes as you type. Paste this in and press play:

   ```graphql
   {
     movies(query: "space", first: 2) {
       totalCount
       pageInfo { hasNextPage endCursor }
       nodes { id title reviewCount averageStars }
     }
   }
   ```

6. Or ask from the terminal.

   ```bash
   curl -X POST "http://localhost:8080/graphql" -H "Content-Type: application/json" \
     -d '{"query":"{ movies(query: \"space\", first: 2) { totalCount nodes { id title reviewCount averageStars } } }"}'
   ```

   Either way you get a page of movies back:

   ```json
   {
     "data": {
       "movies": {
         "totalCount": 4,
         "pageInfo": { "hasNextPage": true, "endCursor": "b2Zmc2V0OjI=" },
         "nodes": [
           { "id": "cb188ef6-14e7-f85f-2f78-924c2ab26b28", "title": "Deep Space Gardeners", "reviewCount": 5, "averageStars": 3.4 },
           { "id": "dfefa450-5454-6a4d-a4aa-95a9b047c17b", "title": "Postcards from Outer Space", "reviewCount": 1, "averageStars": 3 }
         ]
       }
     }
   }
   ```

   The sample movies are all made up. *Deep Space Gardeners* averages 3.4 stars from five reviews, which seems fair for a film about weeding in zero gravity.

7. Run the tests while you're here.

   ```bash
   dotnet test
   ```

</Steps>
